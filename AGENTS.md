# Repository Guide

## Boundaries

- The root is an orchestration layer, not a JavaScript or Python package. Run npm commands from `frontend/` and `uv`/Alembic commands from `backend/`.
- Backend code is capability-oriented: cross-cutting infrastructure belongs in `app/core/`, shared application code in `app/common/`, and domain behavior in the matching `app/systems/<capability>/` package.
- `auth`, `users`, `departments`, `modules`, `fields`, and `records` now contain persistence models and schemas. CRUD APIs for the configurable-data entities remain intentionally deferred; do not add placeholder endpoints.
- `audit` is implemented as an application-only ORM audit system; Adminer, Alembic, raw SQL, and external database clients are outside its capture boundary.
- `frontend/AGENTS.md` is generated by Next.js 16. Read the relevant local guide under `frontend/node_modules/next/dist/docs/` before changing framework conventions or configuration.

## Commands

- Backend setup: `cd backend && uv sync`; required local settings load from the root `.env`.
- Backend verification: `uv run ruff check . && uv run mypy app && uv run pytest`. Pytest enforces 80% coverage.
- Standard future list endpoints use `app/common/listing/`; define endpoint-specific sort/search specs and do not retrofit the existing audit cursor endpoint without an explicit API decision.
- Focused backend test: `uv run pytest tests/test_health.py` or append `-k <name>`.
- PostgreSQL audit integration test: `TEST_DATABASE_URL=... uv run pytest tests/test_audit_integration.py`.
- Frontend setup: `cd frontend && npm ci`.
- Frontend verification: `npm run lint && npm run typecheck && npm run build && npm run test:e2e`.
- Focused browser test: `npm run test:e2e -- tests/home.spec.ts --project=chromium`.
- Full stack: copy `.env.example` to `.env`, replace both placeholder secrets, then run `docker compose up --build`. Caddy serves the app on `APP_PORT` (8080 by default).
- Validate Compose without creating `.env`: `docker compose --env-file .env.example config --quiet`.

## Runtime Details

- Local Next.js development proxies `/api/*` to `BACKEND_URL` (default `http://localhost:8000`); Compose routes `/api/*` and FastAPI docs through Caddy instead.
- The backend container runs `alembic upgrade head` before Uvicorn. Make schema changes through `backend/migrations/`, then verify against PostgreSQL with `uv run alembic check` while the database is available.
- `DATABASE_URL` and `SECRET_KEY` are required backend settings. Never add production defaults; tests set isolated values in `backend/tests/conftest.py`.
- Usernames are normalized to lowercase, passwords require at least 12 characters and use Argon2, registrations always create the `member` role, and bearer tokens expire after 30 minutes by default.
- PostgreSQL-specific models use `JSONB`; do not substitute SQLite for migration or schema verification.
- Domain SQLAlchemy models inherit `app/core/base_model.py`, which supplies UUIDv7 `id`, `created_at`, `deleted_at`, `is_deleted`, `updated_at`, and nullable UUID `performed_by` columns referencing `users.id` with `ON DELETE SET NULL`. `AuditLog` is the immutable exact-schema exception and does not inherit `BaseModel`.
- Roles are seeded by Alembic with `admin` and `member`; registration explicitly assigns the `member` role. Permissions are stored as JSONB but current authorization remains role-name based.
- The UUIDv7 primary-key migration is forward-only; restore a database backup rather than attempting to downgrade it.
- Audit snapshots are minimal before/after JSONB diffs; sensitive fields are redacted, and `AuditLog` must never be modified or audited recursively.
- Use normal audited ORM entity mutations for writes. Bulk and raw ORM mutation statements are rejected because they bypass reliable per-record snapshots.
- Local file data is mounted from root `storage/` to `/app/storage`; the directory is tracked but its contents are ignored.
- Adminer connects to the Compose host `postgres` and is exposed only on `127.0.0.1:${ADMINER_PORT:-8081}`; do not route it through Caddy.
