# Sandbox behavior map

Baseline: commit 7ca93d32; owners updated for the F3 consolidation on base d6af8fa0. Loop titles are quoted as source templates, with `${…}` left unexpanded. Paths are under `frontend/tests`. Owners name the file and title only, because line numbers go stale on the next edit. Source `—` means no criterion, contract, or bug is evident in the test or its comments. `D4` marks a protected test (consolidation.md D4): a 401/403/404 denial, reader or guest access, data isolation, or a regression-shaped race (the comment or title describes a stale or late response; no commit evidence was checked, so treat these as protected until history says otherwise).

Layer column: `http` runs a browser (`page` fixture); `isolated` runs in Node without a browser. The Sandbox `http` family is `http/sandbox-relationship-mappings.spec.ts`, `http/sandbox-inspector.spec.ts`, `http/sandbox-triggers.spec.ts`, `http/sandbox-test.spec.ts`, `http/sandbox-history.spec.ts`, `http/sandbox-header.spec.ts`, and `http/sandbox-sweep.spec.ts`, on the shared fake backend in `http/helpers/sandbox-api.ts`. The first file starts each journey with every Advanced block open (a remembered viewer state), because it covers lifecycle and settings, not disclosure. Isolated rows that render a `.tsx` component go through `isolated/sandbox/static-markup.ts`, which turns the Playwright JSX runtime objects back into React elements.

Known gaps: none from plan item 25. Select choice ID reconciliation (`reconcileSelectOptions`) is exported and owned by `isolated/sandbox/select-options.spec.ts`, and the seven-state work-in-progress rule is `helpers/work-in-progress.ts`, owned by `isolated/sandbox/work-in-progress.spec.ts`; no http probe sets a conflict or a dirty designer draft alone, so their wiring at the call sites has no test.
