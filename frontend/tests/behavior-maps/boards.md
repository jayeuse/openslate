# Boards behavior map

Baseline: commit 7ca93d32. Loop titles are quoted as source templates, with `${…}` left unexpanded. Paths are under `frontend/tests`; `:N` is the line of the `test(` call. Source `—` means no criterion, contract, or bug is evident in the test or its comments. `D4` marks a protected test (consolidation.md D4): a 401/403/404 denial, reader or guest access, data isolation, or a regression-shaped race (the comment or title describes a stale or late response; no commit evidence was checked, so treat these as protected until history says otherwise).

Layer column: `http` runs a browser (`page` or `browser` fixture). `http (no page)` lives in `http/` but takes no `page` fixture: it renders `renderToStaticMarkup`, calls a reducer, or stubs `globalThis.fetch`. Those tests are isolated-layer proofs in the wrong directory (109 of 217 `test(` sites in the 13 `http/boards-*` files). `isolated` rows appear only where an http test of this family repeats the rule.
