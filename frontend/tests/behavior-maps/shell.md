# Shell and settings behavior map

Work package F8 of `docs/plans/test-suite-tier-2-5.md`: the organization settings (profile, logo, look), personal theme and device display preferences, the private profile and regional settings, Help, the shared person card, aggregate calendar journeys, workspace orientation, motion, dialogs and sample-data labels. Paths are under `frontend/tests`. A title with `${…}` is a loop; the template is quoted as written in the source.

Source marks: `D4` is a protected test (consolidation rule D4): `denial` (401/403/404), `authorization` (role gating), `guest access`, `data isolation` (account switch, curtain, foreign data), `stale write` (409 or stale revision) or `regression` (a late, held, lost or older response). `fail-closed` is a malformed or unavailable read that must not be trusted. Group IDs (`G1`…) and table IDs (`M1`…) refer to the F8 consolidation analysis; the removals are in `docs/plans/test-ledger.md`.
