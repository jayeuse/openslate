# Manage behavior map

Baseline: commit fd412418 (the Manage specs changed since only in 84eb72cd, one locator in `manage-audit-api`); owners updated for the F6 consolidation. Paths are under `frontend/tests`. Owners name the file and title only, because line numbers go stale on the next edit; loop titles are quoted as source templates, with `${…}` left unexpanded.

Layer column: `http` runs a browser (every Manage `http` test takes `page`); `isolated` runs in Node without a browser; `isolated (contract)` is a case that `describeContracts("Manage", …)` generates from `isolated/contracts/manage-contract.spec.ts`.

D4 marks (consolidation.md D4), in the Source column: `D4: denial | authorization | data isolation` is a 401/403 refusal, a role gate or an account-switch isolation; `D4: privileged-read concealment` is a refused read that must hide cached data; `D4: regression-shaped` is a test whose title or comment describes a stale, late, delayed or held response (no commit evidence was checked, so these stay protected). `fail-closed` marks a malformed or unavailable read that must not be trusted. `X#`, `P#` and `G#` point at the matrix candidates and duplicate groups of the F6 analysis.

Counts after F6: 5 `http/manage-*` files with 84 expanded runs (audit 16, exports 25, jobs 25, journeys 12, recovery 6; baseline 98), 2 unchanged isolated tests in `isolated/manage-state.spec.ts` (deleted in plan item 25 with the dead code they tested), 152 new isolated rows in `isolated/manage/` (Jobs adapter 35, audit adapter 21, backup rules 48, organization rules 39, Software version panel 9) and 26 contract cases (18 before; 8 added for the workspace calendar, brand, lifecycle and logo adapters). Every new isolated row and contract case failed when its production line was broken (176 breaks), except five rows that two production lines refuse: the protocol-relative, absolute and backslash Jobs subject links (the path checks and the URL-origin check), a text/html audit CSV with a count over 10,000 (media type and count), and a non-API error as a stale revision (the instanceof and status checks). Four lines have no row that fails when they alone are broken: the `//` and URL-origin link checks, the backup retry key `.min(1)` (the key pattern already needs one character) and the never-rendered `current` status text of the Updates panel. Every behavior below names one owner.

Known gaps (each needs a production change and the user's approval): P7 is done: `queryManageActivity`, `buildActivityCsv`, `uniqueValues` and `MANAGE_ACTIVITY_PAGE_SIZE` had no caller and were deleted with `manage-state.spec.ts` (plan item 25). Module-private rules with only http owners: the audit filter-to-request mapping and the workspace day bounds (P1), the audit row text and preview CSV (P2), the audit refusal messages (P3), the export password admission messages (P4), the Jobs retry error classes (P5) and the Jobs admission derivation (P6). `listWorkspaceLogoFiles` has no contract case: the harness builds the first `anyOf` branch of `GET /api/files` (the Library list with `creator_labels` and `storage_used_bytes`), but the server answers a logo list with the plain `FileListResponse` (`files/router.py`). Organization tests that overlap the F8 organization specs (G9) are unchanged and wait for F8. The file names `manage-refactor-journeys` and `manage-security-recovery` no longer describe their content.
